# Monitored fermion reference sheet

`monitored_fermion_reference_sheet.pdf` is an updated edition of the attached
`monitored_fermion_state_preparation_references.pdf`, with the original guide
preserved as source material.

The update:

- adds both Lavasani--Alavirad--Barkeshli papers on monitored topological
  transitions;
- corrects the author of Ref. 46 from `A. H. Bhuiyan` to `A. Bhuiyan`;
- updates the scan date and corpus totals from 100/36 to 102/38 works.

The new papers are numbered 41a and 41b so the original numbering remains
stable. The editable additions are in `lavasani_additions.tex`; the two visual
corrections are specified in `corrected_source_pages.tex`. The corrected front
page and author page are flattened at 300 dpi before final assembly so the
obsolete text does not remain searchable underneath the correction.

The final PDF order is: corrected source page 1; original pages 2--5; the
Lavasani additions; corrected source page 6; and original pages 7--12.
