# 01_p1_chern_dynamics

Standalone versioned P1 experiment for trajectory-resolved real-space Chern convergence only. The v4 execution contract preserves the v3 scientific design and exact cycle-level continuation, but makes the Google Drive API—not DriveFS—the durability authority. Every older P1 and W1 folder remains unchanged. New results write to `MyDrive/classA_final_production_outputs/production_25sample_p1_chern_v4/01_p1_chern_dynamics`.

The immutable matrix has `L=16,24,32,64`, `n_shell=1,2,None`, 25 random half-filled Slater trajectories per case, perfect correction, random serial updates, `n_a=0.5`, and exactly `L` cycles. At the initial state and every completed cycle, ten distinct periodic trijunction centers are freshly and deterministically sampled for each trajectory. The radius-`0.4L` Chern values and their within-trajectory center mean are the only scientific products.

Open `run_production_bundle.ipynb` on an A100. The production queue runs or resumes the required `L=64`, `n_shell=1`, sample-0 qualification automatically; the completed qualification becomes a real checksum-verified production archive, not discarded work. Inspect the default resume report before setting `RESUME_REPORT_ONLY=False`.

The `L=16,24,32` cases retain five immutable five-trajectory final archives, while every `L=64` trajectory has its own immutable final archive. During an active shard, the runner uploads one checkpoint after every completed physical cycle. It requires server metadata to match the parent, filename, byte count, and SHA-256 before publishing a separately verified pointer; only then is the preceding generation deleted. That checkpoint contains the occupied frame, rank diagnostics, NumPy/Torch RNG state, and Chern-observer accumulators, so a rerun continues at the next cycle without duplicating observations. A 7.5-hour queue session stops cleanly at a server-visible cycle boundary and can be rerun until the trajectory finishes. Only one committed checkpoint generation exists for the active shard (roughly 0.5--0.6 GiB at `L=64`); local staging can temporarily add one generation under `/content` without consuming Drive quota. The final checkpoint is deleted only after the archive and receipt are independently server-verified. The complete matrix still contains 120 final archives. No covariance, Bott index, density, entropy, tangent, convergence history, purity product, ordered Born record, or native checkpoint state is retained in those final archives. After all archives verify, enable the analysis cell to merge exactly global samples `0..24` and produce PDF/PNG figures and compact CSV summaries.

The notebook requests one Google authorization per fresh runtime, checks account-wide quota before work, and runs a tiny remote-commit probe. The runner calls `classA_U1FGTN_gpu.run_markov_circuit` and uses occupied-frame states without dense covariance materialization. `production_config.json` is immutable run intent; regenerate copied sources with `_maintenance/sync_bundle_sources.py`.
