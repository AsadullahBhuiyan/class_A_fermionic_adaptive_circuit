# Prior Colab designs

This directory contains the preserved earlier production architecture and its validation,
control, replay, and completion bundles. They remain runnable for provenance, unfinished
approved work, and comparisons, but are intentionally separated from the redesigned
standalone campaigns.

`01_p1_existing_completion` is frozen internally and exists only to finish the original
25-trajectory P1 matrix. The other directories implement the earlier fixed-geometry v4
bundle family. Do not treat a prior-design output as an output of a redesigned campaign.

Shared runners and maintenance tools remain one level above this directory.
