## Copy and verify

From the repository root, run:

```bash
python scripts/archive_cold_tier.py --destination-root /data/abhuiyan
```

The revised runner processes five manifests and writes to a distinct
`class_A_fermionic_adaptive_circuit_large_results_20260817` destination. Each file is
checksummed after copying and the entire destination is then read a second time for
independent verification. Verification requires an exact file inventory: missing,
changed, symlinked, and unexpected destination entries all fail the receipt. Receipts
are written under `PROJECT_ADMIN/archive_manifests/receipts/`.
A restarted tier run validates and reuses completed receipts, then resumes at the first
unfinished dataset. The tools refuse to overwrite destination files, partial copies,
manifests, or receipts and never delete source data.

Before creating the archive, preflight requires a different filesystem, checks that no
archive subdirectory traverses a symlink, and requires enough free space for all remaining
expected bytes plus the larger of 10 GiB or a 2% reserve.

The same preflight also requires the live source inventory, byte sizes, and nanosecond
mtimes to match all five selected manifests before it trusts an existing receipt or
copies a file. Any post-manifest source drift aborts the tier run.

Expected verified total: 1,535 files and 837,778,719,908 bytes. A fresh destination needs
at least 854,534,294,306 free bytes, including the 2% reserve. A completed
receipt still records `source_deletion_authorized=false`; source removal remains a new,
